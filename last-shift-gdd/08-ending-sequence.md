# Urutan Ending

Urutan kamera berikut MUST dijalankan berurutan. Input pemain MUST terkunci selama urutan (PLR-04).

| ID | Langkah |
|---|---|
| END-01 | Pemain keluar dari ventilasi dan melihat cahaya putih. Audio chase berhenti. |
| END-02 | Cahaya dan suara bertransisi menjadi monitor komputer dan dengung kantor. |
| END-03 | Kamera bergerak ke monitor gelap dan memperlihatkan pantulan wajah karakter. |
| END-04 | Kamera turun ke kartu identitas dengan foto dan nama yang sama. |
| END-05 | Monitor menyala. Pesan dari ibu masih terbuka (NAR-ITEM-02) dan satu notifikasi baru berbunyi sekali. Foto di tepi monitor terlihat (NAR-ITEM-01). |
| END-06 | Kamera bergeser ke samping meja dan mengungkap tubuh karakter di kursi. |
| END-07 | Koran di meja mengonfirmasi bahwa pegawai ditemukan meninggal setelah lembur (NAR-04). Koran MUST NOT dipakai untuk menjelaskan setiap detail halusinasi. |
| END-08 | Fade to black dan tampilkan judul LAST SHIFT. |

## Aturan audio ending

| ID | Aturan |
|---|---|
| END-09 | Ending MUST NOT memakai musik. Hanya dengung kantor dan satu bunyi notifikasi. |
| END-10 | Alarm halusinasi menghilang menjadi dengung monitor (layer Transition, lihat `11-audio-direction.md`). |

## Konsistensi visual

- Pantulan monitor, kartu identitas, foto, pesan, dan wajah korban MUST konsisten secara visual.
- Jam monitor menunjukkan dini hari dan catatan tenggat terlihat (NAR-ITEM-03).
- Tidak boleh ada bukti kebakaran objektif (NAR-01).
